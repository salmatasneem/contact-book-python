# Contact Book Application (Python)

## 📌 Description
This is a command-line Contact Book application developed using Python.  
It allows users to add, search, display, edit, and delete contacts.  
The contact details are stored permanently in a text file using file handling.

## 🛠 Features
- Add new contact
- Search contact
- Display all contacts
- Edit existing contact
- Delete contact
- Data stored in a text file (`contacts.txt`)

## 💻 Technologies Used
- Python 3
- File Handling
- Loops and Conditional Statements

## ▶️ How to Run
1. Install Python 3
2. Download the repository
3. Run the file:
   ```bash
   python contact_book.py
